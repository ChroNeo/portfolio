## ปัญหา

การจัดการนิทรรศการและกิจกรรมโดยทั่วไปมักต้องใช้หลายระบบแยกกันสำหรับการลงทะเบียน
การตรวจสอบการเข้าร่วม และการออกใบประกาศนียบัตร บางส่วนยังคงพึ่งพาเอกสารกระดาษอยู่
ความกระจัดกระจายนี้ทำให้ขั้นตอนล่าช้าและข้อมูลผิดพลาดได้ง่าย ยากต่อการตรวจสอบย้อนหลัง
หลังจบงาน จึงอยากรวมขั้นตอนทั้งหมด ตั้งแต่การลงทะเบียน การเช็คอินบูธ แบบประเมินความ
พึงพอใจ ไปจนถึงการส่งใบประกาศนียบัตร ให้อยู่ในแพลตฟอร์มเดียวที่ทั้งผู้จัดงานและผู้เข้าร่วม
ใช้งานได้จริงโดยไม่ติดขัด

## วัตถุประสงค์และขอบเขต

<img src={organizerImage.src} alt="ผู้จัดงาน" style="display: block; margin: 1.5rem 0;" />

ระบบนี้พัฒนาขึ้นเพื่อรองรับผู้ใช้งาน 3 บทบาทหลัก ได้แก่ **ผู้จัดงาน** (สร้าง/จัดการนิทรรศการ
บูธ และดูสถิติ) **เจ้าหน้าที่ประจำบูธ** (เช็คอินผู้เข้าร่วมด้วย QR Code) และ **ผู้เข้าร่วมงาน**
(ลงทะเบียน ทำแบบประเมิน รับใบประกาศนียบัตร) ทั้งหมดผ่าน LINE เป็นช่องทางเดียว

ขอบเขตที่ระบบ **ทำ** ในเวอร์ชันนี้: การลงทะเบียนผู้เข้าร่วม, การเช็คอินผ่าน QR Code,
แบบประเมินความพึงพอใจ, การออกใบประกาศนียบัตรอิเล็กทรอนิกส์อัตโนมัติเมื่อผ่านเกณฑ์,
และแดชบอร์ดสถิติแบบเรียลไทม์สำหรับผู้จัดงาน

ขอบเขตที่ระบบ **ยังไม่ทำ** ในเวอร์ชันนี้: การส่ง Broadcast Message ถึงผู้เข้าร่วมทั้งหมด
พร้อมกัน (ติดข้อจำกัดของแพ็กเกจ LINE OA แบบฟรี) และระบบชำระเงินสำหรับงานที่มีค่าลงทะเบียน

## สถาปัตยกรรมระบบ

<img src={structureImage.src} alt="โครงสร้างระบบ" style="display: block; margin: 1.5rem 0;" />

ระบบแบ่งออกเป็น 3 ชั้นหลัก:

1. **ฝั่งผู้ใช้ (Client)** — LINE Official Account + LIFF (LINE Front-end Framework)
   สำหรับหน้าจอลงทะเบียน แบบประเมิน และแสดงใบประกาศนียบัตร ทำงานอยู่ภายในแอป LINE
   โดยตรง
2. **ฝั่ง Backend** — Fastify (Node.js + TypeScript) รับ Webhook Event จาก LINE,
   ประมวลผล Business Logic และให้บริการ REST API แก่หน้าแดชบอร์ดของผู้จัดงาน
3. **ฐานข้อมูล** — MySQL แบ่งเป็น 3 โดเมนหลัก (Exhibition / Unit / Survey) เชื่อมโยง
   กันผ่านตาราง `exhibitions` เป็นศูนย์กลาง

<Callout type="info">
  แนวคิดหลักของสถาปัตยกรรมนี้คือให้ LINE ทำหน้าที่เป็น "หน้าบ้าน" ที่ผู้ใช้คุ้นเคยอยู่แล้ว
  ส่วน Backend และฐานข้อมูลทำหน้าที่เป็น "หลังบ้าน" ที่จัดการ Logic และข้อมูลทั้งหมด
</Callout>

## การตัดสินใจสำคัญ

ถูกติดตั้งอยู่ในโทรศัพท์ของคนส่วนใหญ่อยู่แล้ว ผู้ใช้จึงสามารถลงทะเบียน เช็คอิน ทำแบบประเมิน

## ความท้าทาย

LINE Messaging API และ LIFF ทั้งคู่ต้องการการเชื่อมต่อแบบ HTTPS เท่านั้น ซึ่งทำให้การพัฒนา
บนเครื่อง Local ทำได้ยาก เพราะไม่มี Endpoint แบบ HTTPS ให้ Webhook เรียกใช้ จึงแก้ปัญหา
ด้วย Cloudflare Tunnel เพื่อเปิดเซิร์ฟเวอร์ Local ออกสู่ภายนอกผ่าน HTTPS ระหว่างพัฒนา ทำให้
สามารถทดสอบการรับส่งข้อมูลผ่าน Webhook และหน้า LIFF ได้ก่อนที่จะ Deploy จริง

<Callout type="warning">
  หากไม่มี HTTPS Tunnel การยืนยัน Webhook และการเริ่มต้นทำงานของ LIFF ของ LINE จะไม่
  สามารถทำงานกับเซิร์ฟเวอร์ Local ได้เลย ไม่มีทางเลี่ยงข้อกำหนดนี้ได้ แม้แต่ในขั้นตอนทดสอบ
  เบื้องต้น
</Callout>

โครงสร้างฐานข้อมูลยังต้องปรับปรุงหลายรอบระหว่างการพัฒนา เมื่อมีความต้องการใหม่เกิดขึ้น
เช่น การเชื่อมโยงแม่แบบใบประกาศนียบัตรเข้ากับนิทรรศการแต่ละงาน หรือการติดตามความ
คืบหน้าของแบบประเมินรายผู้ใช้ และทีมยังต้องใช้เวลาเรียนรู้เครื่องมือหลายอย่างที่ไม่เคยใช้มาก่อน
ระหว่างทาง ทำให้ระยะเวลาพัฒนายืดออกไปมากกว่าที่วางแผนไว้

## ผลลัพธ์

ระบบที่พัฒนาเสร็จช่วยให้ผู้จัดงานสามารถจัดการนิทรรศการ บูธ แบบสอบถาม และแม่แบบใบ
ประกาศนียบัตรได้จากแดชบอร์ดเดียว พร้อมสถิติการมีส่วนร่วมแบบเรียลไทม์ เจ้าหน้าที่ประจำบูธ
สแกน QR Code ของผู้เข้าร่วมงานผ่าน LINE เพื่อบันทึกการเช็คอิน ส่วนผู้เข้าร่วมงานสามารถ
ลงทะเบียน ทำแบบประเมินความพึงพอใจ และดาวน์โหลดใบประกาศนียบัตรอิเล็กทรอนิกส์ได้ทั้งหมด
ภายใน LINE เมื่อผ่านเกณฑ์การเข้าร่วมที่กำหนด จากการทดสอบและการใช้งานจริง ระบบสามารถ
บันทึกและประมวลผลข้อมูลการมีส่วนร่วมได้อย่างถูกต้อง ช่วยลดภาระงานของผู้จัดงานและลดการ
ใช้กระดาษ

ข้อจำกัดที่ทราบอยู่แล้วคือ ฟังก์ชัน Broadcast Message ของ LINE ยังไม่ได้เปิดใช้งาน
เนื่องจากข้อจำกัดจำนวนข้อความต่อเดือนของบัญชี LINE Official Account แบบฟรี ทำให้การ
แจ้งข่าวสารไปยังผู้เข้าร่วมงานทั้งหมดพร้อมกันยังไม่รองรับเต็มรูปแบบในเวอร์ชันปัจจุบัน

## แนวทางพัฒนาต่อ

- เปิดใช้งาน Broadcast Message เมื่ออัปเกรดแพ็กเกจ LINE OA
- เพิ่มแดชบอร์ดวิเคราะห์ข้อมูลเชิงลึก (Analytics) สำหรับผู้จัดงาน เช่น อัตราการเข้าร่วมต่อบูธ
- รองรับหลายภาษาในหน้า LIFF สำหรับงานนิทรรศการนานาชาติ
- เพิ่มระบบชำระเงินสำหรับงานที่มีค่าลงทะเบียน
